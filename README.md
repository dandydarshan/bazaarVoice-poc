# Bazaarvoice API Fastify Project (TypeScript)

This project is a Fastify application, written in TypeScript, that integrates with the Bazaarvoice API to fetch review statistics. It demonstrates a structured approach to building Fastify applications with autoloading for routes and plugins, schema validation using TypeBox, and a separate client for interacting with external APIs.

## Project Structure

The project follows a structure that separates concerns and leverages Fastify's autoload capabilities:

-   `src/`: Contains all the TypeScript source code.
    -   `app.ts`: The main application entry point where Fastify is initialized and plugins are registered.
    -   `plugins/`: Houses Fastify plugins.
        -   `bazaarvoice-client.ts`: A client plugin responsible for making requests to the Bazaarvoice API. It decorates Fastify with `fastify.bazaarvoiceClient.fetchStats()`.
        -   `bazaarvoice.ts`: A plugin that depends on `bazaarvoice-client` and decorates Fastify with `fastify.getReviewStats()`, providing a higher-level interface for fetching review statistics.
    -   `routes/`: Contains route definitions.
        -   `review-stats/`: A directory for the `review-stats` route.
            -   `index.ts`: Defines the route (e.g., `GET /review-stats`) and attaches the schema and handler. Autoloaded by Fastify.
            -   `handler.ts`: Contains the request handling logic for the route.
            -   `schema.ts`: Defines request and response schemas for the route using `@sinclair/typebox`.
-   `dist/`: Contains the compiled JavaScript code for production, generated by `npm run build`.
-   `test/`: Contains test files.
    -   `helper.ts`: A helper for building the Fastify app instance for testing.
    -   `routes/review-stats.test.ts`: Tests for the `/review-stats` endpoint.
-   `package.json`: Defines project metadata, dependencies, and scripts.
-   `tsconfig.json`: TypeScript compiler configuration.
-   `README.md`: This file.

## Features

-   **TypeScript**: Provides static typing for better code quality and maintainability.
-   **Fastify Autoload**: Automatically loads plugins and routes from specified directories.
-   **TypeBox**: Used for defining and validating request/response schemas.
-   **Separated API Client**: The `bazaarvoice-client` plugin encapsulates the logic for interacting with the Bazaarvoice API.
-   **Structured Routes**: Routes are organized into their own directories with separate files for the route definition, handler, and schema.

## Installation

1.  Clone the repository (if you haven't already).
2.  Install the project dependencies:

    ```bash
    npm install
    ```

## Running the Application

### Development Mode

To run the application in development mode with `ts-node` (which handles TypeScript compilation on the fly and automatically restarts on file changes if configured with `nodemon` or similar):

```bash
npm run dev
```

The server will typically start on `http://localhost:3000`.

### Production Mode

1.  Build the TypeScript code into JavaScript:

    ```bash
    npm run build
    ```

    This command compiles the TypeScript files from `src/` and outputs the JavaScript to the `dist/` directory, based on the `tsconfig.json` configuration.

2.  Start the server using the compiled code:

    ```bash
    npm start
    ```

    This command runs the application from the `dist/` directory. The server will typically start on `http://localhost:3000`.

## Available Endpoints

### GET /review-stats

This endpoint fetches review statistics from the Bazaarvoice API for a predefined set of product IDs and statistics type ("Reviews").

**Request:**

```
GET /review-stats
```

**Response:**

The endpoint returns a JSON response containing the review statistics, validated against the schema defined in `src/routes/review-stats/schema.ts`.

**Example Response:**

```json
{
  "Results": [
    {
      "ProductStatistics": {
        "ReviewStatistics": {
          "AverageOverallRating": 4.75,
          "TotalReviewCount": 120
        }
      }
    }
  ],
  "HasErrors": false
}
```
*(Note: The actual data will vary based on the API response.)*

## Running Tests

To run the test suite (using `tap`):

```bash
npm test
```

This command will execute all test files ending with `.test.ts` in the `test/` directory. Tests include mocking the Bazaarvoice API interaction to ensure reliable and fast unit/integration tests for the route.
